# Admin UI Platform

## Übersicht
Das Repository **admin-ui** bietet eine moderne Dashboard-Benutzeroberfläche zur Verwaltung von Anwendungsdaten, Benutzern und Systemkonfigurationen auf Basis von Next.js, React, TailwindCSS und Shadcn UI.

## Projektstruktur & Architektur
- `app/`: Next.js App-Router Struktur mit Layouts, Dashboard-Ansichten und Routen.
- `components/`: Wiederverwendbare UI-Komponenten (Buttons, Formulare, Tabellen).
- `hooks/`: Benutzerdefinierte React Hooks für Daten-Fetching und Zustandsverwaltung.
- `lib/`: Hilfsfunktionen und Schnittstellen-Konfigurationen.
- `styles/`: Globale Stylesheets und Tailwind-Konfigurationen.

## Hauptfunktionalitäten
- **Moderne UI-Architektur**: Verwendung von Shadcn UI Komponenten für ein einheitliches Erscheinungsbild.
- **Server-Side Rendering & App-Router**: Performante Seitennavigation über Next.js.
- **Responsives Dashboard**: Anpassungsfähiges Layout für Mobil- und Desktopgeräte.

## Ausführung & Nutzung
Die Ausführung des lokalen Entwicklungsservers erfolgt nach der Installation der Abhängigkeiten mit `pnpm dev` oder `npm run dev`.
